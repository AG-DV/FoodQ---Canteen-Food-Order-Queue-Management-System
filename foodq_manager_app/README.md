# FoodQ Manager Module

This Flutter app contains only the Manager part of FoodQ.

## Basic Manager Functions Implemented

- Admin Dashboard
- Stall congestion levels
- Complaint tracking
- Performance reports
- Automated alerts

Customer and Vendor functions are not included because this part belongs only to the Manager role.

## Run

```bash
flutter pub get
flutter run
```

Choose Chrome or an Android emulator when Flutter asks for a device.

## Main File

- `lib/main.dart` - all Manager screens and mock data.
- `docs/manager_part2_documentation.md` - short report content for the Manager part.
